_PLACEHOLDERS
=============
Shipped fallbacks. Not a content folder — never edited by you, and not
scanned by lib/content.ts. Empty slots are rendered as CSS gradient
placeholders (see lib/placeholders.ts) rather than needing a binary
fallback file here, so this folder currently has nothing in it. Reserved
in case a future primitive needs a shipped default asset (e.g. a default
poster frame).
